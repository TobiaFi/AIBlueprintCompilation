# AI Blueprint Compilation v1.0

This mod adds Domain Derelict and Remnant ship blueprints as drops from Domain-era Survey Ships, Motherships, and Remnant Nexuses.
There's only one of each blueprint around, though, so be careful what you do with them. Build your own automated fleet, or let the powers of the sectors fight against each other with forbidden weaponry. What could possibly go wrong?
